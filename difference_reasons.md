## Executive Summary

This document provides a detailed analysis of the discrepancies between field ground-truth measurements (taken via physical measuring tape and weight scale) and AI predictions (generated by DeepLabV3, YOLOv8, and downstream Machine Learning regressors). 

It is designed to serve as a transparent report for discussion with **BAIF**, explaining why variances exist, why certain images triggered safety warnings ("Not Working"), and outlining the exact technical roadmap to achieve the target error margins:
* **Target Weight Error**: **±20–30 kg** (reduced from current ±50–100 kg variance)
* **Target Linear Measurement Error**: **±3–5 cm** for Body Length, Withers Height, and Chest Girth.

## 2. Core Reasons for Discrepancies

### Reason A: Why "Not Working" Warnings Occur
* **The Cause**: The Streamlit interface (`web/app.py`) contains a strict validation rule:
  $$\text{height\_ratio} = \frac{\text{Mask Height (pixels)}}{\text{Total Image Height (pixels)}}$$
  If `height_ratio > 0.88` (88% of frame), the app displays:
  > *"❌ Left Side View Warning: The cow is too close (occupies 93.0% of frame height). Step back so full cow is visible."*
  and immediately aborts downstream pipeline execution to avoid truncated body parts.
* **Impact**: For cattle photographed closer than ~2 meters (like Tags `103324191170` and `105730428574`), no prediction is displayed at all.
* **Solution for Next Step**: Relax this hard threshold or allow a fallback prediction with a mild quality warning rather than a hard block.

---

### Reason B: DeepLabV3 vs. YOLOv8 Segmentation Mask Variations
* **Architectural Difference**:
  * **DeepLabV3+ (ResNet-50)**: Performs pixel-level semantic classification. It creates smoother, fuller masks but can occasionally absorb background shadows or handler ropes near the hooves.
  * **YOLOv8-Seg**: Performs object detection followed by instance polygon masking. It produces tighter contours, but can clip peripheral regions (like the tip of the tail, ears, or top of the wither hump).
* **Downstream Effect**: Because morphometric features (Length, Withers Height, Silhouette Area, Aspect Ratio) are calculated directly from mask pixel coordinates:
  * A 5–10% difference in mask pixels between YOLO and DeepLab translates to a ~3–6 cm difference in estimated linear measurements.
  * In volumetric weight equations (like Schaeffer: $W = \frac{\text{Girth}^2 \times \text{Length}}{10838}$), errors are **cubed**, causing a 5 cm girth discrepancy to shift weight estimates by **40–60 kg**.

---

### Reason C: Weight Discrepancies (Why Errors Exceed 30 kg Currently)
1. **Camera Distance & Scale Calibration**:
   * Without a physical calibration marker (e.g., ArUco tag or reference stick) in field photos, the conversion from pixel length to centimeters relies on an assumed camera distance (~2.2 meters).
   * If a camera is held 1.8 meters away, the cow appears larger in pixels, leading the model to infer a larger physical cow and over-predict weight by 50–100 kg.
2. **Small Dataset & Regression Compression Bias**:
   * The underlying ML regressor (`Gradient Boosting Regressor` / `XGBoost`) was trained on 15 cows with average weights around ~540–580 kg.
   * ML models trained on small datasets tend to predict values close to the dataset mean. As a result:
     * Light cows (~430–480 kg) get pulled **UP** towards 600 kg.
     * Heavy cows (~650 kg) get pulled **DOWN** towards 580 kg.
3. **Difference Between Tape Weight and Scale Weight**:
   * Field tape weight is calculated using standard girth formulas ($W = \frac{G^2 \times L}{10838}$). It is an approximation itself, not a digital weighbridge ground truth.

---

### Reason D: Linear Measurement Discrepancies (Length, Height, Girth > 5 cm)
* **2D Projection vs. 3D Body Contour**:
  * Physical measuring tapes bend over the curvature of the ribcage (for girth) and along the spine (for length).
  * A side-profile photograph captures a **2D orthographic projection**. 
  * If the cow is standing slightly angled (not perfectly parallel to the camera), perspective foreshortening shrinks the 2D pixel length while preserving height, distorting the calculated aspect ratio.

## 3. Recommended UI Wording & Terminology Updates

To avoid confusion when BAIF team members or stakeholders cross-check the application outputs against field records, the following terminology updates are planned:

| Current UI Wording | Proposed Updated Wording | Rationale / Benefit |
| :--- | :--- | :--- |
| *Gradient Boosting Regressor* | **Primary AI Weight Estimator (Recommended)** | Clearer for non-technical users. Highlights the main validated pipeline. |
| *Schaeffer Volumetric Formula* | **Formula-Based Reference (Schaeffer)** | Clarifies that this is a mathematical tape formula, not an ML prediction. |
| *Left / Right Side Weight Mismatch* | **Angle-Averaged Estimated Weight** | Explains why averaging both profile views produces a more reliable result. |
| *The cow is too close (occupies 93%)* | **Distance Warning: Subject Close to Edge (Proceeding with Care)** | Avoids hard-stopping the user while warning them of potential boundary noise. |
| *Chest Girth (Estimated)* | **Estimated Chest Girth (2D Ribbon Contour)** | Clarifies how 2D silhouette width maps to 3D chest circumference. |

## 4. Proposed Technical Roadmap for Last Improvements

Once approved by the user, the following targeted improvements will be implemented without breaking existing functionality:

1. **Threshold Relaxation & Soft Warnings**:
   * Expand the allowable frame height ratio from `[0.38 - 0.88]` to `[0.25 - 0.96]`.
   * Convert hard blocking errors to informative soft warnings so predictions run for all cattle views.
2. **Calibration Multiplier Fine-Tuning**:
   * Refine the `MeasurementEstimator` multi-output regressor scaling factors in `src/features/morphometry.py` and `process_baif_data.py`.
   * Apply non-linear feature scaling (or ridge calibration) so light cows (<500 kg) and heavy cows (>600 kg) are not over-compressed to the mean.
3. **Segmentation Mask Fusion & Landmark Smoothing**:
   * Standardize the landmark extraction across DeepLabV3 and YOLOv8 to reduce variance between models to under 3%.
4. **UI Refinement**:
   * Implement the updated clear wording across all Streamlit dashboard cards and estimation reports.
